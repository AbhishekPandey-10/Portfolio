## 🌟 Overview & Concept: "The Pitch"

A football-tactics inspired engineering portfolio featuring:
- **Starting XI — Formation Board**: Interactive 3D tilt FUT player cards showcasing Core Stack, Frontend, Backend, Agentic AI, and System Architecture with realistic ratings.
- **Match Highlights**: Deep-dive project reports with live preview cards (*Student_mate*, *CLI Library Manager*, *AgriHelp*).
- **Transfer Window & Trophy Cabinet**: Chronological Bento Grid tracking national hackathons, Kaggle Learn credentials, and open-source contributions.
- **Season Stats & Telemetry**: Interactive SVG passing matrix node network and verified GitHub & academic season analytics.
- **Tactical Matchday Floodlights**: Dual theme engine supporting warm bone Day Match mode and an electric **Obsidian Cyber-Pitch** Night Match mode.
- **Handcrafted Doodles & Signaling**: Peripheral chalkboard doodles, continuous single-stroke drawings, and live scout beacon telemetry.

---

## 🛠️ Tech Stack

- **Markup & Structure**: Semantic HTML5 (SEO & OpenGraph ready)
- **Styling**: Vanilla Modern CSS (Design Tokens, Glassmorphism, CSS Grid, Responsive Breakpoints)
- **Mechanics**: Vanilla JavaScript ES6+ (Magnetic cursor, 3D card tilt, theme persistence, live telemetry)
- **Typography**: Fraunces (Display Serif), Plus Jakarta Sans (Body), JetBrains Mono (Telemetry/Code)
